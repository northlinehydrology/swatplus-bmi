# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussion about the
work. Harassment and personal attacks aren't tolerated in issues, pull requests or any other
project space.

Report a problem to the maintainer, Andrew Sommerlot, at andrew@northlinehydrology.com. Reports
are kept confidential. The maintainer will respond, and may warn, suspend or remove anyone who
doesn't follow this code, as the Contributor Covenant's enforcement guidelines describe.
